\# Portfolio Profesional - Joel Ruiz



Portfolio digital personal creado con \*\*Bootstrap 5\*\*, \*\*HTML\*\*, \*\*CSS\*\* y \*\*JavaScript\*\* para presentar mi perfil como desarrollador web en formación.



\## Descripción



Este proyecto es un portfolio personal pensado para mostrar mi perfil, mis habilidades técnicas, mi experiencia, mis proyectos destacados y mi información de contacto.



Está diseñado con una estructura responsive para adaptarse correctamente a móvil, tablet y escritorio.



\## Secciones del portfolio



\- Hero / presentación.

\- Sobre mí.

\- Resumen profesional.

\- Habilidades.

\- Portfolio de proyectos.

\- Servicios.

\- Contacto.
